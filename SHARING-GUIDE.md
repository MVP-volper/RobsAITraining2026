This repository demonstrates all aspects of the GitHub Copilot training:

#### ✅ Setup (3 steps)
- Opening Copilot in VS Code
- Installing the extension
- GitHub authentication

#### ✅ Core Features (5 steps)
- **Plan Agent** - Using AI to create implementation plans
- **Agent Mode & MCP Servers** - Leveraging MCP server capabilities
- **Code Completions** - Inline code suggestion acceptance

- **Copilot Actions** - Context menu and error list actions

   ```bash
   git clone https://github.com/MVP-volper/RobsAITraining2026.git
   cd RobsAITraining2026
   ```

2. **Read the Overview**
   - Start with `README.md` for a quick summary
